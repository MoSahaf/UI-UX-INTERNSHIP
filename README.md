# UI/UX Development

This repository contains my completed UI/UX Development Internship projects under the Auspify Technologies 4-Week Practical Learning Program.

During this internship, I completed six practical UI/UX design tasks covering wireframing, user flows, high-fidelity UI design, interactive prototyping, dashboard design, e-commerce design, and complete product design case study.

## Completed Tasks

### Task 1 – Mobile App Wireframe Design

Created low-fidelity wireframes for a mobile application with a focus on layout structure, user flow, navigation, usability, and accessibility.

### Task 2 – Landing Page UI Design

Designed a modern and responsive landing page with a focus on page layout, typography, color schemes, visual hierarchy, and call-to-action elements.

### Task 3 – Mobile App Prototype Design

Designed high-fidelity mobile application screens and created an interactive prototype demonstrating user journeys, navigation, and interactions.

### Task 4 – Dashboard UI/UX Design

Designed a professional dashboard for data management and visualization, including navigation, widgets, charts, cards, tables, and interactive components.

### Task 5 – E-Commerce App UI/UX Design

Designed a complete e-commerce application focused on the shopping experience, including product listings, product details, cart, checkout, and interactive prototype flows.

### Task 6 – Complete Product Design Case Study

Created a complete UI/UX product design solution including user research, competitor research, personas, user journeys, wireframes, high-fidelity screens, design system, interactive prototype, and case study documentation.
